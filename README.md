# 消费分析

GitHub Pages 静态网站。PDF 在浏览器内解析；交易、分类修改仅保存在当前浏览器的本地存储，不上传服务器。

## 使用

选择一份或多份 PDF 即可导入。当前支持同版式广发文本账单；扫描件、加密 PDF、无法完整对账的文件会拒绝导入。重复账单自动跳过，账单内重复交易保留。

支持账户、交易币种、月份筛选，环形图、二级分类、商户及逐笔明细。默认欧元，中文名称为参考译名。

账单不会跨浏览器或设备同步。清除浏览器数据会删除本地记录；请保留原 PDF。公开仓库不含个人账单、交易记录、截图或浏览器存储。

## 开发

Node.js 22.12+：

```
npm ci
npm run build
```

构建产物位于 dist。GitHub Actions 自动部署 main 分支到 Pages。

PDF.js worker、字体和字符映射随网站同源提供，不使用第三方 PDF 上传服务。PDF.js 遵循 Apache-2.0，许可见 public/PDFJS-LICENSE。
